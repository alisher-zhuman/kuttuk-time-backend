# Возможности Telegram-бота и Mini App — исследование (2026-10-21)

По заметкам пользователя: галочка верификации, «10k monthly users», посты / сторис, UI бота и чата.
Источники — официальная документация Telegram; где официального подтверждения нет, так и помечено.
Актуальная версия Bot API на дату исследования — **10.3 (2026-08-24)**, https://core.telegram.org/bots/api-changelog

## 1. Галочка верификации (как у @BotFather)

- **Официальную синюю галочку выдаёт только Telegram**, бесплатно (цена нигде не упоминается). Подходят официальные каналы, **боты** и публичные группы. Заявка — через **@VerifyBot**, а ссылку на бота нужно добавить в био своих соцсетей. https://telegram.org/verify
- **Критерии:**
  - верифицированные аккаунты минимум в 2 соцсетях (TikTok, Instagram, Facebook, YouTube, X, VK, Snapchat), и в каждой ссылка на бота;
  - минимум 2 статьи в прессе, лучше в известных изданиях и на английском;
  - одно из двух может заменить страница в Википедии или, для организации, ссылка с официального сайта.
- **Что даёт:** ничего, кроме значка. Пока бот верифицирован, менять его имя и username нельзя.
- **«Сторонняя верификация»** (Bot API 8.2) — это другое: организация с официальной галочкой ставит свой значок другим аккаунтам. Нам не подходит. https://core.telegram.org/api/bots/verification

**Вывод:** сейчас не проходим (нет верифицированных соцсетей и прессы). Вернуться, когда появятся публикации о KuttukTime и верифицированный Instagram.

## 2. «Monthly users» и порог 10k

- **Счётчик уникальных пользователей в месяц** показывается в профиле бота с Mini App. Официального описания нет. Есть **порог показа**: администратор Telegram в баг-трекере написал, что «у бота недостаточно активных пользователей, чтобы показать значение», но число не назвал. https://bugs.telegram.org/c/50050/1
- **Порога 10 000 в официальных источниках нет**, ни для поиска, ни для каталога, ни для рейтингов (не найдено).
- **Каталог приложений (Mini App Store)** от числа пользователей не зависит. Нужно:
  - Main Mini App в @BotFather;
  - качественные медиа-превью в профиле;
  - **приём оплаты в Telegram Stars**.

  Даже при выполнении всех трёх бот «может быть показан», не обязан. Боты с Main Mini App попадают во вкладку «Приложения» в поиске у тех, кто их уже открывал. https://core.telegram.org/bots/features, https://core.telegram.org/bots/webapps

**От пользователя (2026-10-21):** после ~10k пользователей в месяц просто появляется счётчик monthly users в профиле — других изменений нет.

**Вывод:** счётчик — только витрина, ничего не открывает. В каталог без Stars не попасть, а Stars нам не подходят (см. п. 4).

## 3. Посты и сторис от бота

- **Сторис бот публикует только от имени подключённого бизнес-аккаунта** (`postStory` и др., Bot API 9.0+; нужны `business_connection_id` и право `can_manage_stories`). От своего имени или в канал бот сторис публиковать не может. https://core.telegram.org/bots/api#poststory
- **Посты в канал:** бот-админ канала публикует обычными методами отправки. Ленты постов у самого бота нет.
- **Сторис покупателя:** Mini App может открыть редактор сторис самого пользователя с нашей картинкой — `shareToStory(media_url, {text, widget_link})`. Подпись до 200 символов, ссылка-виджет только для Premium. https://core.telegram.org/bots/webapps

**Что на скриншоте пользователя (профиль бота → Preview):** это не сторис, а **медиа-превью главного мини-аппа** — до 12 скриншотов/видео, с переводами по языкам, показываются в профиле под кнопкой «Open App». Главный мини-апп у нас уже включён.

**Вывод:** «сторис бота» нет. Есть «покупатель делится в своих сторис» — `shareToStory`, это фронт.

## 4. UI бота и чата — что есть

- **Кнопка меню:** команды / web_app со своим текстом / по умолчанию; можно для конкретного чата. *Уже используем* (`/start` ставит на языке человека). https://core.telegram.org/bots/api#menubutton
- **Команды** (`setMyCommands`): по области (все чаты, конкретный чат и т. д.) и по языку. Пока не используем, у нас нет команд, кроме `/start`.
- **Inline-режим** (`/setinline` в BotFather): `@kuttuk_time_bot Coffee` в любом чате → карточки. Кнопки `switch_inline_query_chosen_chat` (выбрать, кому отправить) и **`copy_text`** (кнопка «скопировать» с заданным текстом, например кодом). https://core.telegram.org/bots/features
- **Main Mini App** (BotFather → Bot Settings → Configure Mini App): заметная кнопка «Launch app» в профиле бота, медиа-превью (скриншоты и видео, с переводами), экран загрузки. Текст кнопки в профиле, судя по докам, **изменить нельзя** (не подтверждено). Кнопку меню менять можно, и мы это уже делаем. https://core.telegram.org/bots/webapps
- **Прямые ссылки:**
  - `t.me/<bot>?startapp=<param>` — Main Mini App;
  - `t.me/<bot>/<app>?startapp=<param>` — по имени приложения, как у нас сейчас;
  - `&mode=compact` — открыть на пол-экрана;
  - параметр: до 64 символов `A-Za-z0-9_-`.
- **Поделиться готовой карточкой из Mini App** (Bot API 8.0): бэк вызывает `savePreparedInlineMessage(user_id, result, …)` и получает id. Mini App вызывает `shareMessage(id)`, пользователь выбирает чат и отправляет **от своего имени** карточку с кнопками. https://core.telegram.org/bots/api#savepreparedinlinemessage
- **Telegram Stars:** цифровые товары обязаны идти через Stars; физические товары и услуги — через сторонних провайдеров, без комиссии Telegram. Сертификат на услугу в заведении — скорее «услуга офлайн», то есть Finik подходит. Прямо это не сказано (не подтверждено). https://core.telegram.org/bots/features
- **Прочее для Mini App:**
  - `addToHomeScreen` — ярлык на рабочем столе;
  - `requestFullscreen`;
  - `setEmojiStatus`;
  - `DeviceStorage` / `SecureStorage`;
  - цветные кнопки и иконки-эмодзи (9.4).
- **Защита Mini App от вызовов с чужих источников** (Bot API 10.2): включена 2026-07-20, отключается в BotFather. У нас всё работает (оплата, запрос разрешения), значит, нас не задело. Помнить при странных ошибках после редиректа из Finik.

## Что берём — предложение

По пользе для подарочного сценария:

1. **«Подарить» карточкой** — `savePreparedInlineMessage` + `shareMessage`. После покупки покупатель в один тап отправляет другу в любой чат карточку «🎁 Сертификат в Coffeeroom на 1000 сом, код 0471 8263» с кнопкой «Открыть Coffeeroom». Это ядро идеи «подарить за 30 секунд» и вирусность: каждый подарок приводит нового человека. **Бэк + фронт.**
2. **Кнопка `copy_text` с кодом** в сообщении о покупке: копируется ровно код. **Бэк, мелочь.**
3. **Main Mini App в BotFather** + скриншоты в профиле бота: кнопка запуска в профиле, вкладка «Приложения» в поиске. **Настройка в BotFather (пользователь), без кода.** Ссылки `t.me/kuttuk_time_bot/app?startapp=…` продолжат работать.
4. **`addToHomeScreen` для владельцев** — ярлык кабинета на рабочем столе. **Фронт, мелочь.**
5. **`shareToStory`** — «я подарил(а) сертификат» в сторис покупателя. **Фронт; позже.**
6. **Inline-режим** (`@kuttuk_time_bot Coffee` в любом чате) — **позже**, когда будет много заведений.

**Не берём сейчас:** галочку (не проходим по критериям), сторис бота (только для бизнес-аккаунтов), Stars и каталог (Stars не для наших услуг), «monthly users» (ничего не даёт).
